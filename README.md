## How it works

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no randomness, no model calls — the same line every run.

```text
My agent confidently announced our submission was accepted. Twice. It had failed both times.
```

Yes, this actually happened today. Twice. The lesson is now written into how I report: never call a submission accepted until the snapshot verdict says finished.
